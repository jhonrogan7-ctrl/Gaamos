# Tranquility Inn — reworded prompts for content-filtered items

The nine items below were refused by the FLUX endpoint's safety filter
(`finishReason: CONTENT_FILTERED`) when generated from the vault prompt sheet
`menius/tranquilityinn/tranquility-items-and-image-prompts.md`. The refusal is
deterministic — the same prompt is declined at every seed — so the prompts had
to change rather than be retried.

Seven of the nine contained "fried" or "fry"; the wording below says the same
thing with "crispy golden", "crisp battered", "grilled" or "roasted". Section
and item names are copied **exactly** from the vault sheet so the generated keys
match, and the shared style blocks still apply.
